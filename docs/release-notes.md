# AfterShelf alpha

Desktop game library for Windows x64, macOS Apple Silicon and macOS Intel.

- Browse F95 and LewdCorner with separate source attribution for each game.
- Track linked games through recent-update listings and verified thread versions.
- Download from user-selected hosts, reveal archives, install full ZIP releases and launch games.
- Apply engine-based save/preference transfer profiles; preserve old releases until installation completes.
- Check the chosen games folder on startup, retain missing-game records and discover new extracted games.
- Export redacted text diagnostics for bug reports.

Engine profiles are experimental. Real-game compatibility varies; report problems with the engine, platform, app version and diagnostics. Unknown engines, patches and executable installers require manual installation. Passwords, multipart files and unsupported archives use an external extraction app. HTML games currently open in the default browser.

Windows Web Setup downloads its application package from this release; keep the accompanying `.7z` release asset available. The Windows ZIP is a directly usable alternative. macOS builds are distributed as DMG and ZIP packages. These alpha builds are not notarized or signed with a publisher certificate. Application self-updating is not implemented yet.
